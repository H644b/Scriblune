## Honest implementation boundaries

- Supported uploads: static PDF, PNG, JPEG, WebP. Password-protected/corrupt/animated inputs are rejected with preserved originals and explicit errors. No Office, SVG, HEIC, TIFF, audio/video, or school/LMS integration.
- Required signup codes and optional email two-step verification need a working verified-domain Resend sender. Deployment-specific child privacy and consent procedures remain operator responsibilities.
- Local browser demo is scripted; real tutoring requires configured models and a working private database/storage stack. No fabricated AI response is presented as live.
- SVG editing is implemented, including pressure brush and masks. Raster fill is bounded to 180,000 scanline entries; shapes remain editable. Eraser removes hit objects rather than destructively trimming stroke segments. No handwriting recognition guarantee is made.
- Mathematical canvas text uses Unicode; full TeX rendering is in chat. Multi-object manipulation supports moving/grouping; resize handles are currently for single selected objects.
- Only the active full page is mounted; thumbnail buttons are not window-virtualized. Current workspace fetches the transcript and up to 300 recent events. Very long transcripts/page rails require pagination/virtualization before high-volume use.
- Replay covers the last available explanation's still-current marks, without reverting later edits. It is not a full historical timeline editor.
- Local recovery preserves pending actions, but concurrent edits can require explicit conflict resolution/retry. It is not a full offline-first collaboration engine.
- Memory retrieval is bounded lexical retrieval plus exact excerpts and a source-linked model ledger. It does not promise perfect recall or infer sensitive traits. Ledger generation failure leaves the original conversation intact.
- Feedback questions are event-grounded deterministic templates and balanced options. Rating changes the order of relevant questions (for example, surfacing pacing earlier after a low rating) while wording and balanced options remain unchanged; elaboration stays optional. No automatic retraining exists.
- Export uses canonical original orientation and rasterizes original-plus-annotations into PDF; viewport rotation is a viewing preference. Export runs as bounded sequential server work, not a persistent export queue. A failed export can be retried without changing submission.
- Continue creates a new draft from the submitted scope. It preserves page roles and annotations but starts a new conversation and fresh review eligibility.
- Accessibility includes native dialogs, keyboard controls, labels, focus visibility, responsive layouts, and reduced motion. Full screen-reader/device audits and formal conformance assessment remain to be performed.
- Supabase migration, restricted login, the public VM/container deployment, and the real sign-in/upload cycle are verified. Personal mailbox placement and operational backup/retention processes remain operator tasks. Deployment and targeted tests do not constitute a production certification or broad scale/reliability assessment.
